# Rack Mount Go security policy

## Report privately

Do not open a public issue for a suspected vulnerability, exposed credential, malicious dependency, compromised automation identity, or workflow/runner compromise.

Use [GitHub private vulnerability reporting](https://github.com/grosspoetrysystems/rack-mount-go/security/advisories/new) for Rack Mount Go. Do not include vulnerability details in a public issue or discussion.

Include what you can safely provide:

- affected version or commit;
- impact and reproduction steps;
- proof of concept or sanitized logs;
- relevant pull request, workflow, job, agent run, base, and head identifiers; and
- whether any secret, runner, bot identity, release, or downstream user may be affected.

Remove credentials and personal data from attachments. Do not run a suspicious contribution again merely to collect more evidence.

## Response

Rack Mount Go's maintainers will acknowledge receipt, establish a private communication path, contain active risk, and coordinate disclosure. Response time depends on capacity and severity; Rack Mount Go does not promise a fixed service level.
